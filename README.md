# Сайт студенческих объединений

## Быстрый старт

1. Установи Node.js (если ещё нет): https://nodejs.org (версия LTS)
2. Открой терминал в папке проекта и выполни:
   ```
   npm install
   npm start
   ```
3. Откроется адрес вида `http://localhost:8080` — там сайт с live-обновлением
   (меняешь файл → страница в браузере обновляется сама).

## Как добавить организацию

Открой `src/_data/organizations.json` и добавь новый объект в массив:

```json
{
  "slug": "moe-obedinenie",
  "name": "Название организации",
  "shortDescription": "Одна короткая фраза для карточки на главной.",
  "description": "Полный текст, который будет на странице организации. Можно несколько предложений.",
  "image": "/images/moe-obedinenie.jpg",
  "color": "#7C5CFF",
  "social": {
    "instagram": "https://instagram.com/...",
    "telegram": "https://t.me/...",
    "vk": "https://vk.com/...",
    "website": "https://..."
  }
}
```

- `slug` — латиницей, без пробелов, уникальный (это часть адреса страницы).
- `color` — акцентный цвет карточки/страницы, любой HEX.
- Если у организации нет какой-то соцсети — просто удали эту строку из `social`, кнопка не отобразится.
- Картинку положи в `src/images/` под именем, указанным в `image`.

### Необязательные поля

Если организации это не нужно — просто не добавляй поле, ничего не сломается.

```json
"support": {
  "label": "Помощь: @username",
  "url": "https://t.me/username"
},
"presentation": {
  "date": "11.09",
  "time": "16:00",
  "place": "Уточняется"
}
```

- `support` — отдельная кнопка-ссылка (например, контакт для вопросов), отображается на странице организации.
- `presentation` — если у организации скоро презентация/встреча, появится бейдж на карточке и блок на странице с датой, временем и местом.
- `image` — можно не указывать вовсе, если фото/лого ещё нет: вместо картинки покажется плейсхолдер с первой буквой названия в акцентном цвете. Как появится файл — просто добавь поле `"image"`.
- `programs` — если у организации есть несколько направлений/форматов мероприятий (как разделы, а не сплошной текст), можно перечислить их списком вместо (или вместе с) `description`:
  ```json
  "programs": [
    { "title": "Название направления", "description": "Описание." }
  ]
  ```
  Они отобразятся отдельными карточками на странице организации.
- `note` — короткая заметка вместо блока презентации (например «набор закрыт»). Если заданы оба поля — `presentation` и `note` — покажется только `presentation`.
- `highlights` — список коротких пунктов (например «чему научишься»), отобразится чек-листом с галочками:
  ```json
  "highlights": ["Пункт первый", "Пункт второй"]
  ```

Больше ничего трогать не нужно — страница сгенерируется автоматически.

## Как выложить сайт (хостинг Netlify)

1. Залей папку проекта на GitHub (создай репозиторий, `git init` → `git add .` → `git commit` → `git push`).
2. Зайди на https://netlify.com → "Add new site" → "Import an existing project" → выбери свой GitHub-репозиторий.
3. В настройках сборки укажи:
   - Build command: `npx @11ty/eleventy`
   - Publish directory: `_site`
4. Нажми Deploy — через минуту сайт будет доступен по адресу вида `your-site.netlify.app`.
5. Свой домен подключается в разделе Domain settings.

После этого при каждом `git push` сайт будет пересобираться и обновляться автоматически.

## Сборка для проверки локально (без dev-сервера)

```
npm run build
```
Готовый сайт появится в папке `_site` — её и видит хостинг.
