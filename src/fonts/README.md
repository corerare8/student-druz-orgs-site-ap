# Шрифты Actay

CSS уже настроен на использование шрифтов **Actay** (основной текст) и **Actay Wide** (заголовки) через `@font-face` в `style.css`.

Сами файлы шрифта сюда не включены (Actay — коммерческий/лицензируемый шрифт, у меня нет доступа к его дистрибутиву). Чтобы шрифты заработали, добавьте в эту папку следующие файлы (в форматах woff2 и woff):

- `Actay-Regular.woff2` / `Actay-Regular.woff` — для основного текста
- `ActayWide-Bold.woff2` / `ActayWide-Bold.woff` — для заголовков (жирное начертание)
- `ActayWide-Regular.woff2` / `ActayWide-Regular.woff` — для заголовков (обычное начертание, опционально)

Пути в CSS: `/fonts/Actay-Regular.woff2` и т.д. — т.е. файлы должны лежать по адресу `src/fonts/...` (после сборки — `_site/fonts/...`).

Пока файлов нет, сайт автоматически использует шрифт **Manrope** (Google Fonts) как запасной — выглядит похоже, сайт не сломается.
